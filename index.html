Get emoticons from a profile link
A local page can't read Steam directly (browser security), so it's a quick copy — their inventory must be public:
1 · paste the profile link above, hit Open ↗.
2 · a page of text opens — select all (Ctrl+A), copy.
3 · paste it into the big box, hit Load. Cards, backgrounds etc. are dropped automatically.

Your own list is easiest from the Steam chat emoticon picker, or steamcommunity.com/my/inventory/#753_6.

3 · Gap width — this is what makes it line up

— none —
One ⠀ is only ~⅓ of an emoticon wide, so the useful range is 1.5–3 voids per cell. Auto-fit measures the exact ratio for a 16px emoticon, matching the preview. Ruler copies a test message — paste it in Steam and read the number off it if auto-fit is slightly out. The fractional value is spread across each row (2.5 → 2,3,2,3…) so long rows don't drift.

Notes

• Steam does not render a square grid: emoticons are ~26–32 px wide while a void is ~9 px. The gap width above is what converts your grid into something Steam draws straight.
• Pixel-perfect alignment is only guaranteed with a blank emoticon as the gap, since an emoticon is by definition exactly one emoticon wide.
• Steam chat accepts ~1000 characters per message; profile comments allow more.
• Emoticons you don't own still show as text to you, but render for anyone who sees the message, so borrowed codes work fine.
